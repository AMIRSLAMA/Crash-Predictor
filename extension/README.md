# Crash Predictor — Live Round Collector

## التثبيت
1. نزّل المستودع ZIP من GitHub وفك الضغط.
2. افتح Chrome ثم `chrome://extensions`.
3. فعّل Developer mode ثم اختر Load unpacked وحدد مجلد `extension`.
4. افتح موقع اللعبة في تبويب مستقل، واضغط أيقونة الإضافة ثم «ربط هذه الصفحة بالجامع».
5. وافق على إذن نطاق اللعبة. الإضافة ستعيد تحميل الصفحة لالتقاط WebSocket من بدايته.
6. افتح أو حدّث https://amirslama.github.io/Crash-Predictor/ في تبويب آخر.

## ما الذي يُجمع؟
تقرأ الإضافة رسائل SignalR المسماة OnCrash وOnResult فقط، وتحفظ رقم الجولة والمضاعف النهائي. لا تجمع الرهانات أو الرصيد أو بيانات تسجيل الدخول أو رسائل Cashouts.

## ملاحظات
- يجب إبقاء تبويب اللعبة مفتوحًا.
- إذا كانت أسماء حقول النتيجة مختلفة في إصدار اللعبة، فلن تُحفظ الجولة حتى نطابق الحقول مع رسالة فعلية.
- النسبة المعروضة تكرار تاريخي متحرك، وليست ضمانًا أو معرفة مسبقة بنتيجة الجولة التالية.
- إيقاف الجامع من نافذة الإضافة يزيل سكربتات الالتقاط المسجلة.

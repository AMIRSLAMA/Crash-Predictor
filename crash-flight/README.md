# CRASH FLIGHT

برنامج Windows مستقل مبني على Electron. يفتح نافذة لوحة التحكم ونافذة لعبة منفصلة داخل التطبيق، ثم يراقب إطارات WebSocket الواردة من نافذة اللعبة عبر Chrome DevTools Protocol.

## التشغيل أثناء التطوير
```powershell
npm install
npm start
``

## الاختبار
```powershell
npm test
``

## الاستخدام
1. شغّل التطبيق.
2. ستفتح نافذة CRASH FLIGHT ونافذة اللعبة.
3. سجّل الدخول يدويًا داخل نافذة اللعبة إذا لزم الأمر، ثم افتح لعبة Crash.
4. تابع عدادات WebSocket وSignalR وسجل الجولات في لوحة التحكم.

## الحدود والخصوصية
- لا يقرأ التطبيق جلسة Chrome الخارجية؛ نافذة اللعبة داخل التطبيق لها جلسة مستقلة وقد تتطلب تسجيل الدخول مرة أخرى.
- يقرأ التطبيق إطارات WebSocket الواردة من نافذة اللعبة المدمجة، ويفك فقط رسائل SignalR النصية المعروفة.
- لا يخزن إطارات الشبكة الخام أو كلمات المرور أو Cookies أو Tokens.
- يسجل OnStart وOnStage وOnCrash وOnResult عندما تصل رسائلها.
- لا يوجد ادعاء بالتنبؤ بالمضاعف أو معرفة موعد الانفجار مسبقًا. قياس توقيت OnCrash بعد وصوله تحليل رجعي.
- قد تمنع سياسات الموقع فتح اللعبة داخل نافذة مدمجة أو قد يتغير بروتوكول الرسائل؛ عندها نحتاج ضبط التكامل بناءً على تشخيص حقيقي.

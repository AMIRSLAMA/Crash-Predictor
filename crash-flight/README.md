# CRASH FLIGHT

برنامج Windows مستقل مبني على Electron، يحتوي على لوحة تحكم ونافذة لعبة مدمجة داخل التطبيق.

## التشغيل أثناء التطوير
```powershell
npm install
npm start
```

## الاختبار والبناء
```powershell
npm test
npm run build:win
```

## الاستخدام
1. شغّل التطبيق.
2. اضغط «فتح نافذة اللعبة» من لوحة CRASH FLIGHT.
3. سجّل الدخول يدويًا داخل نافذة اللعبة إذا لزم الأمر، ثم افتح لعبة Crash.
4. تابع حالة رصد WebSocket، وعدد الإطارات والأحداث، وسجل الجولات.
5. تتحرك الطيارة الافتراضية عند وصول حدث بداية الجولة، ويعمل تأثير الانفجار عند وصول حدث نهاية الجولة.

## حدود الرصد
- يراقب التطبيق إطارات WebSocket الواردة من نافذة اللعبة المدمجة عبر Chrome DevTools Protocol.
- يتعرف على رسائل SignalR النصية المعروفة مثل OnStart وOnStage وOnCrash وOnResult.
- إذا تغيّر بروتوكول الموقع أو كانت الرسائل ثنائية/مشفرة فلن يستطيع المحلل قراءتها، وستظهر العدادات دون أحداث مفهومة.
- تأثير الطائرة متزامن مع الحدث الذي وصل بالفعل؛ ليس إنذارًا مسبقًا ولا يتنبأ بموعد الانفجار أو المضاعف.
- يعرض محلل الرسائل بيانات وصفية فقط: اسم الحدث ووقت الاستلام والفاصل عن الحدث السابق والوقت منذ بداية الجولة. لا يعرض أو يخزن محتوى الرسائل الخام.
- لا يحفظ التطبيق إطارات الشبكة الخام أو كلمات المرور أو Cookies أو Tokens. يحتفظ بملخص الجولات داخل ذاكرة جلسة التطبيق فقط.
- نافذة اللعبة لها جلسة مستقلة وقد تتطلب تسجيل الدخول مرة أخرى.

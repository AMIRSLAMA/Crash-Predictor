# Crash Predictor — تحليل سجل Crash

واجهة عربية لتحليل **المضاعفات التاريخية** واختبار الإحصاءات محليًا.

> **تنبيه:** ألعاب Crash تعتمد على نتائج عشوائية/آليات اللعبة. لا يستطيع هذا المشروع ضمان الجولة القادمة أو نسبة نجاح 70% أو كشف نتيجة قبل وقوعها. المؤشرات هنا وصفية للسجل الذي تدخله وليست توصيات مراهنة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## الاستخدام
1. الصق المضاعفات السابقة في مربع السجل (كل قيمة مفصولة بمسافة أو فاصلة أو سطر).
2. اضغط «حلّل السجل».
3. راجع المتوسط والوسيط والتوزيع وآخر الجولات.
4. البيانات تحفظ محليًا في المتصفح على جهازك.

## الاختبارات
```bash
npm test
```

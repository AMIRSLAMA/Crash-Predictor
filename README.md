# Crash Predictor — تحليل سجل Crash

واجهة عربية لتحليل المضاعفات التاريخية وجمع النتائج التي ينسخها المستخدم بنفسه.

> **تنبيه:** لا يستطيع المشروع ضمان الجولة القادمة أو كشف نتيجة قبل وقوعها. التحليلات وصفية للنتائج السابقة وليست توصيات مراهنة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## جامع النتائج
1. افتح قسم «جامع النتائج» في الصفحة.
2. أثناء مشاهدة اللعبة، انسخ رسائل SignalR من Network التي تحمل `OnCrash` أو `OnResult` والصقها في المربع الواحد.
3. اضغط «حلّل واجمع النتائج». يحفظ المتصفح الجولات المستخرجة محليًا باستخدام رقم الجولة لمنع التكرار.
4. إذا أضفت لاحقًا مصدرًا آخر للجولة نفسها، يدمج البرنامج المصدرين ويعلّم اختلاف قيمة الانهيار إن وجد.
5. استخدم «تصدير CSV» أو «تصدير JSON» للاحتفاظ بنسخة احتياطية.

**الخصوصية والنطاق:** لا يتصل التطبيق بموقع اللعبة ولا بحساب المستخدم، ولا يطلب Cookies أو Tokens. لا يحفظ رسائل Network الخام؛ يحفظ فقط رقم الجولة والمضاعفات ومصادرها والتوقيت المتاح. التخزين محلي في المتصفح الحالي، وقد يختفي عند مسح بيانات الموقع أو تغيير المتصفح/الجهاز. لا يوجد تجميع تلقائي في الخلفية؛ يجب لصق الرسائل يدويًا.

## التحليل التاريخي
- الصق المضاعفات السابقة في مربع السجل ثم حلّلها.
- يعرض المتوسط والوسيط والتوزيع ومعدلات الانتقال التاريخية إلى 2x+ مع أحجام العينات.
- هذه مؤشرات وصفية لا تثبت السببية ولا تتنبأ بالجولة التالية.

## CRASH DECODER
يتعرف المحلل على `OnStart`, `OnCrash`, `OnResult`, `OnRegistration`, `OnCashouts`, و`OnProfits`. يربط النتائج بمعرّف الجولة `l`، ويقارن `OnCrash.f` مع `OnResult.f`، ويعرض `OnResult.k` منفصلًا. أحداث الأرباح والسحوبات ليست نتيجة الانهيار.

## الاختبارات
```bash
npm test
```

## الاحتمالات التاريخية والاختبار الزمني

- تعرض الشاشة احتمال تجاوز عتبات 1.5x و2x و3x و5x و10x كنسب تكرار تاريخية، مع فاصل ثقة 95% للعينة.
- لم يعد الرقم المعروض ادعاءً بأن المضاعف النهائي المتوقع معروف؛ إنه احتمال وصفي مستند إلى العينة.
- بعد وصول جولة مكتملة، يسجل التطبيق نتيجة ثنائية لتجاوز 2x ويحسب Brier score؛ الصفر أفضل، ويجب تجميع جولات كثيرة قبل تقييم أي فائدة.
- شغّل `npm run analyze` لإنتاج تقرير JSON قابل لإعادة التحقق يتضمن عدد الجولات الفريدة والتوزيع والاحتمالات واختبارًا زمنيًا 80/20.
- يقارن الاختبار الاحتمال الثابت من بيانات التدريب بتقدير متحرك، ويمنع استخدام نتائج الاختبار في التدريب. لا يوجد ادعاء بأن أيًا منهما يتنبأ بنتيجة عشوائية أو يكشف نتيجة الجولة قبل إعلانها.
